# 每日小宇宙

仅供个人使用的 Android 离线应用。计划、每日安排、健身、收支、娱乐和设置保存在手机应用内部的 SQLite 数据库中。首页标题下方的励志话语可以点击编辑，修改后也会保存在本机。

## 每日安排与待办事项

- 每日安排默认显示在前面：可勾选周一至周日，也可快速选择工作日或每天。安排按开始时间排序，已勾选的排在底部；每天的完成状态独立记录。
- 待办事项：选择开始日期后，未勾选时从该日起持续显示，不显示逾期标记。勾选后仅在勾选当天显示，并变暗、移到底部；次日打开或返回应用时自动删除。当天手动取消勾选后继续保留。
- 从旧版升级时，原有“每天”计划转入每日安排，其他计划保留。

## 收支

- 当前余额可在收支页右上角设置中直接修改，之后随收入与支出流水变化。
- 可设置每月统计周期的起始日（1–31 日）。短月若没有指定日期，使用该月最后一天。
- 统计周期同时作用于本期收入、支出、预算剩余和流水列表。

## 更新安装

使用相同应用签名的新版 APK 覆盖安装时，SQLite 数据库会升级并保留已有数据。不要卸载旧版或在系统设置中清除应用数据；这两种操作会删除手机内的数据。
